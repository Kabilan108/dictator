# Bundled fonts

- Geist Regular and Medium: https://github.com/vercel/geist-font (v1.7.0, via nixpkgs `geist-font`)
- IBM Plex Mono Regular: https://github.com/google/fonts/tree/main/ofl/ibmplexmono

Both families are distributed under the SIL Open Font License 1.1. The corresponding
license files are included here. Geist is the interface face; Plex Mono is used only
for aligned figures such as times, durations, identifiers, and file names.
